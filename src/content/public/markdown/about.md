# About Pius Agboola

I'm a backend engineer based in London, currently completing an MSc in Computer Science at
the University of East London (on a distinction track). I work mainly in Python (Django,
FastAPI) and C# (ASP.NET, .NET 8), with a focus on clean architecture, performance, and
correctness.

Professionally, I've built fintech infrastructure at Touch and Pay Technologies (YC W22) in
ASP.NET, where I improved application performance by 20% and refactored core logic for 50%
efficiency gains. Earlier, at Reymage, I designed REST APIs handling 100k concurrent requests
and kept 95% test coverage across production Django services.

Beyond standard backend work, I build systems around messy information and AI output: a
multi-agent AI loan-reallocation engine (GFA Exchange, Honourable Mention at UKFinnovator by
Ukfin+), RegTech compliance middleware (PACTGuard), a document-intelligence study tool
(StudyBud), and an AI-assisted household meal-planning platform (MealSync). I prefer AI that
is wrapped in a real workflow, with validation, fallbacks, and human review, so the result is
defensible and auditable.

I'm strongest where backend engineering meets applied AI and data work. I like turning a
concrete problem into a working system, then asking the harder questions: where logic should
live, how it is tested, how it fails safely, and how a non-technical person will actually use
it.
