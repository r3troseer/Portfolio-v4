# Full-Stack

Backend is my strongest area, but I build and care about the frontend too. I work with React
and TypeScript, Next.js, Blazor, and PWAs, and I pay attention to whether a system is
actually usable.

Evidence from public projects:
- **UK Shift Calculator**: an offline-first React PWA with local persistence, a built-in
  2024/25 UK tax and NI engine, and CSV/JSON export.
- **MealSync**: React and TypeScript frontend over a FastAPI backend, with shared household
  workflows.
- **GFA Exchange**: React and TypeScript with Zustand for the marketplace and analysis UI.
- **TicketSage**: Next.js frontend with Zustand over a Django REST backend.
- **Online Printing Service (OPS)**: Blazor Server UI for upload, payment, and job
  management.

I move comfortably between the API and the interface, which helps me ship complete features
rather than just endpoints.
