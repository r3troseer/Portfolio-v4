# Backend Engineer

Backend is my core. I design APIs, data models, authentication, service layers, and
background processing in both Python (Django, Django REST Framework, FastAPI) and C#
(ASP.NET Core, .NET 8), with a preference for clean, layered architecture and testable code.

Evidence from public projects:
- **MealSync**: a 4-layer FastAPI backend (API, service, repository, model) with SQLAlchemy
  and Alembic, JWT auth, 77 automated tests, and 93% AI service coverage.
- **Train Booking System (TBS)**: a .NET 8 Clean Architecture API with conflict-free seat
  booking, transactions, and OTP authentication.
- **Online Printing Service (OPS)**: ASP.NET Core Web API on Clean Architecture with
  Redis caching, Azure Blob storage, and background job processing.
- **TicketSage** and **EPrep**: Django REST backends with token auth, payments, and
  scheduled management commands.

Professionally, I improved application performance by 20% at Touch and Pay Technologies
(YC W22) and designed Django REST APIs handling 100k concurrent requests at Reymage with 95%
test coverage.
