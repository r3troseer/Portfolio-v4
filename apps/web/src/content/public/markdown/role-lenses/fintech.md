# FinTech / RegTech

I've worked across financial software, from production fintech infrastructure to hackathon
prototypes that take regulation and inclusion seriously.

Evidence:
- **Touch and Pay Technologies (YC W22)**: built and maintained fintech backend systems in
  ASP.NET, improving application performance by 20% and core-logic efficiency by 50%.
- **GFA Exchange**: an AI loan-reallocation engine for UK SME lending, with a
  privacy-preserving, double-blind marketplace and financial inclusion as a first-class
  metric. Honourable Mention at UKFinnovator by Ukfin+.
- **PACTGuard**: pre-release compliance middleware for AI-era financial communications,
  applying a Pass / Adjust / Check / Terminate decision with evidence-bound explanations.
  FCA-aligned, not FCA-certified; it supports compliance decisions rather than giving advice.
- **EPrep**: Paystack payment integration with transaction records for a subscription-style
  service.

I'm comfortable with the patterns these systems need: authentication, OTP, payments,
transactions, audit trails, and careful handling of sensitive data.
